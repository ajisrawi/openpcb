Route Custom — router do-file

    
The editor exports the board as a SPECCTRA .dsn, runs OpenRoute with this script in a worker, and imports the .ses session. Edit the commands as you would an Allegro _route.do.

    
    
    
      
      
    
  



  

    
Constraints

    
One entry per line. Differential pairs: NAME P_NET N_NET gap tolerance maxUncoupled maxSkew (mm). Length groups: NAME tolerance net1 net2 …. Net length limits: NET min max (use - for none). Zones: NET LAYER x1 y1 x2 y2 [static].

    
    
    
    
    
    
    
    
    
  



  

    
Footprint editor

    
One pad per line: id x y w h shape [th drill] [rot] (mm, shape rect | circle | oval; th 1.0 = through-hole with drill). Silkscreen: one polyline per line, x1 y1 x2 y2 …. Saving under a new name creates a footprint; parts using the old name keep it.

OpenSKILL console

    
SKILL syntax (f(a b) or (f a b), x = 1, obj->prop, foreach, procedure …) with the axl design functions: axlDBGetDesign(), axlSelectByName("COMPONENT" list("U1")), axlDBCreateLine(net layer width points), axlTransformObject(obj ?move list(dx dy) ?angle a), axlDRC(). Edits can be undone with Ctrl+Z.

    
    

    
  



  

    
Collaboration

    
Start a server with openpcb collab-serve board.openboard.json --port 7777, then join. Edits are shared live; locks and partitions keep others out of your objects and areas; checkpoints are named versions anyone can restore.
